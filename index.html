Конфигурации VPN по почте

Amnezia Key Mail создаёт индивидуальные конфигурации для собственного VPN-сервера и отправляет их на почту по запросу из модифицированного клиента Amnezia.

Пользователь указывает имя или идентификатор, адрес электронной почты и количество конфигураций. Для каждого устройства выдаётся отдельный ключ.

Gmail API используется только для отправки писем с аккаунта администратора. Получателям не нужно подключать свой Google-аккаунт или давать доступ к своей почте.

Название OAuth-приложения в Google: Amnezia Widget Mail. Это независимая настройка для собственного сервера, а не официальный сервис команды Amnezia.
