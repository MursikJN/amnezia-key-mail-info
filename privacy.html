Какие данные используются

Для выдачи конфигураций сервис получает имя или идентификатор, почту, количество ключей и идентификатор запроса. Сервер видит IP-адрес соединения; в журнале запросов сохраняется его хеш для ограничения повторных обращений.

Созданные конфигурации содержат приватные VPN-ключи. Конфигурации и сведения о выданных ключах сохраняются на сервере администратора, чтобы повтор запроса не создавал лишние ключи. Служба выдачи не предназначена для сбора истории посещения сайтов.

Доступ к Google

OAuth-приложение Amnezia Widget Mail запрашивает у администратора разрешение gmail.send, а также openid и email для определения аккаунта отправителя. Доступ используется только для отправки запрошенных конфигураций. Приложение не запрашивает разрешений на чтение, удаление или изменение входящих писем.

Токен авторизации хранится на сервере администратора с ограниченными файловыми правами. Он не включается в распространяемый VPN-клиент и не передаётся получателям конфигураций. Для получения ключей пользователям не требуется авторизация Google.

Передача и защита

Запросы приложения передаются по HTTPS. Письма и вложения обрабатываются Google и почтовым провайдером получателя. Данные не продаются и не используются сервисом для рекламы или обучения моделей искусственного интеллекта. Хостинг этих информационных страниц предоставляется GitHub Pages и может вести технические журналы посещений.

Использование данных Google API соответствует Google API Services User Data Policy, включая требования Limited Use. Политика Google.

Хранение и удаление

История выдачи и серверные записи ключей хранятся до удаления администратором. Автоматический срок удаления сейчас не установлен. Отправленные письма остаются в почтовых ящиках в соответствии с настройками их владельцев.

Для удаления записей или отзыва VPN-ключа напишите администратору с почты, указанной в запросе. Администратор может отозвать доступ Gmail в настройках безопасности Google-аккаунта и удалить серверный токен. Это прекращает будущую отправку; уже отправленные письма автоматически не удаляются.
